# AnswerJump

PDF 문제집에서 문제와 정답을 번호로 자동 연결하고, 선택한 문항의 정답만 확인할 수 있게 하는 웹 프로그램입니다.
'프로그래밍과 문제해결' 프로젝트로 만들었습니다.

## 실행 방법

1. `AnswerJump_MVP.html`을 브라우저(Chrome 권장)로 엽니다. PDF.js를 불러와야 하므로 인터넷 연결이 필요합니다.
2. PDF 구성 방식을 고르고 PDF를 선택합니다.
   - 한 파일에 문제와 정답이 있으면 정답이 시작되는 페이지 번호를 입력합니다.
   - 문제 PDF와 정답 PDF가 따로 있으면 두 파일을 모두 선택합니다.
3. '번호 자동 분석하기'를 누르고, 왼쪽 목록에서 문제를 선택합니다.
4. 문제를 푼 뒤 '정답 보기'로 정답과 해설을 확인하고, 맞음·틀림·다시 볼 문제를 기록합니다.

PDF와 학습 기록은 서버로 보내지 않고 브라우저 안에서만 처리·저장합니다.

## 테스트 자료

| 파일 | 내용 | 설정 |
|---|---|---|
| `AnswerJump_테스트교재.pdf` | 문제 5개(1~3페이지) + 정답(4~5페이지) | 정답 시작 페이지 4 |
| `AnswerJump_문제.pdf`, `AnswerJump_정답.pdf` | 위 자료를 문제·정답 파일로 나눈 것 | 두 파일 모드 |
| `AnswerJump_단원테스트교재.pdf` | 3개 단원, 단원마다 1번부터 다시 시작하는 문제 8개(1~2페이지) + 여러 줄 해설(3~4페이지), 페이지를 넘어가는 해설과 반복 머리말 포함 | 정답 시작 페이지 3 |

## 버전 기록

- **v0.1** — PDF 텍스트에서 문항 번호 인식, 같은 번호의 문제·정답 연결, 문제·정답 페이지 미리보기, CSV 저장. 미리보기가 바뀌지 않던 오류를 PDF.js Canvas 렌더링으로 수정.
- **v0.2** — 정답을 기본으로 가리고 선택한 문항의 정답 줄만 공개, 문항별 맞음·틀림·다시 볼 문제 기록(PDF 지문 기준으로 브라우저에 저장), 틀린 문제·다시 볼 문제 필터.
- **v0.3** — 단원마다 번호가 다시 시작하는 문제집 지원, 여러 줄 해설 표시.
  - 번호가 줄어드는 지점(예: 3 → 1)에서 새 구간을 시작하고, 같은 순서의 문제 구간과 정답 구간을 연결합니다.
  - '2단원 도형'처럼 단원 번호로 시작하는 짧은 줄을 단원 이름으로 표시합니다.
  - 정답 번호 다음 줄부터 다음 번호 직전까지를 해설로 묶습니다. 여러 페이지에 반복되는 머리말·꼬리말과 쪽 번호는 제외하므로 페이지를 넘어가는 해설도 이어집니다.
  - 문제와 정답의 구간 수가 다르면(예: 정답 시작 페이지를 잘못 입력) 경고를 표시합니다.
  - 학습 기록을 '구간:번호' 기준으로 저장하고, v0.2에서 저장한 기록은 자동으로 옮겨 옵니다.

## 현재 한계

- 번호가 이미지로만 들어 있는 스캔본은 인식하지 못합니다.
- 2단 편집 문서는 같은 높이의 왼쪽·오른쪽 글이 한 줄로 합쳐져 번호를 놓칠 수 있습니다.
- '1 ③ 2 ⑤ 3 ②'처럼 한 줄에 여러 정답을 모아 둔 빠른 정답표는 첫 번호만 인식합니다.
- 단원이 바뀌어도 번호가 이어지는 문제집은 하나의 구간으로 처리합니다(연결에는 문제 없음).
