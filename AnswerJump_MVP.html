① PDF 파일 선택

PDF 뷰어 기준 페이지 번호입니다. 1페이지부터 세며, 이 페이지 전까지는 문제 영역으로 처리합니다.

텍스트가 선택 가능한 PDF를 지원합니다. 스캔본은 아직 지원하지 않습니다.

② 자동 연결 결과

범위: 한국어 '문제 1', '1.', '1)' 형태와 정답의 같은 번호를 페이지 단위로 연결합니다. 같은 번호가 장마다 반복되거나 번호가 이미지에만 있는 문서는 지원이 제한됩니다. PDF 처리를 위해 첫 실행 시 인터넷으로 Mozilla PDF.js 라이브러리를 불러옵니다. 업로드한 PDF 파일은 서버로 전송하지 않고 브라우저에서 처리합니다.
